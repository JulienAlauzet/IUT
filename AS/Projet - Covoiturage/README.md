# Projet Covoiturage - PHP MVC 🚗

Ce projet a été réalisé durant mon cursus à l'IUT de Montpellier pour approfondir les concepts de la **Programmation Orientée Objet (POO)** en PHP et la gestion de bases de données relationnelles.

### 🏗️ Architecture & Conception
Le projet est entièrement structuré selon le pattern **MVC (Modèle-Vue-Contrôleur)**, garantissant une séparation claire entre la logique métier, la gestion des données et l'interface utilisateur :
* **Model :** Gestion des entités et des interactions avec la base de données via PDO.
* **View :** Interface utilisateur dynamique.
* **Controller :** Logique de l'application et routage des requêtes.
* **Config :** Centralisation des paramètres de connexion et des constantes globales.

### 🛠️ Stack Technique
* **Langage :** PHP 7 (POO).
* **Base de données :** MySQL (gérée via phpMyAdmin).
* **Serveur :** Apache.
* **Frontend :** HTML5 / CSS3.

### 🚀 Fonctionnalités principales
- Gestion des utilisateurs (Inscription / Connexion sécurisée).
- Création et recherche de trajets de covoiturage.
- Persistance des données et intégrité référentielle.
