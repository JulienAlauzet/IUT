# DUT Informatique - Année Spéciale (AS) 💻

Ce dossier regroupe les projets majeurs réalisés durant mon année intensive de DUT Informatique à l'IUT de Montpellier. Chaque projet illustre une compétence spécifique en développement et en conception logicielle.

---

### 📂 Liste des projets

#### 🎲 Projet - Dominion (Java)
Développement d'un moteur de jeu de cartes "Dominion" en **Java**.
* **Compétences :** Programmation Orientée Objet (POO) avancée, Design Patterns, gestion de la logique de jeu complexe.
* **Outils :** Maven, Git.

#### 🚗 Projet - Covoiturage (PHP / SQL)
Création d'une plateforme de mise en relation pour le covoiturage.
* **Compétences :** Architecture MVC, gestion de base de données relationnelle, développement Back-end.
* **Technologies :** PHP natif, MySQL, HTML/CSS.

#### 🔐 Code Game Jam - LFSR (Algorithmie)
Participation à une Game Jam axée sur la cryptographie et les registres à décalage (Linear Feedback Shift Register).
* **Compétences :** Algorithmie pure, manipulation binaire, logique mathématique.
* **Langage :** Java / Python.

#### ⚗️ Projet - QM Breaking Bad
Application de gestion (Quiz ou Inventaire) inspirée de l'univers de la série.
* **Compétences :** Interface utilisateur (UI), manipulation de données et expérience utilisateur (UX).

#### 🛠️ TPs - POO
Ensemble d'exercices pratiques visant à maîtriser les concepts fondamentaux de la POO.
* **Notions :** Héritage, Polymorphisme, Encapsulation, Interfaces.

---

### 🚀 Ce que ces projets démontrent
1. **Adaptabilité :** Capacité à passer d'un langage à un autre (Java, PHP, Python) selon les besoins.
2. **Rigueur :** Application des bonnes pratiques de codage dès les premières étapes de ma formation.
3. **Passion :** Investissement dans des événements comme la Code Game Jam pour relever des défis techniques.
