# Projet Tuteuré : QM BreakingBad 🧪

Ce projet académique a été réalisé au sein d'une équipe de 4 personnes. Il porte sur l'analyse de données de consommation fictives : *"Quel produit mangent les 15-25 ans en regardant Breaking Bad ?"*.

### 👥 Équipe et Encadrement
* **Collaborateurs :** Victoria VICHET, Thibault MATTHEWS et Guillaume DUFOUR.
* **Tutrice :** Mme Madalina CROITORU.

---

### 🎯 Objectifs du projet
* **Analyse de données :** Extraire et dégager des tendances de consommation à partir d'une base de données fictive.
* **Développement Multi-stack :** Création d'une base de données dédiée et d'une interface de consultation Web.
* **Logique Algorithmique :** Traitement des données via des algorithmes Java pour obtenir des statistiques pertinentes.

### 🏗️ Structure & Technologies
* **Back-end Java :** Implémentation de la logique de calcul et de tri (fichiers `Algo.java`, `AlgoPlus.java`).
* **Interface Web PHP :** Développement de l'interface utilisateur pour la visualisation des résultats.
* **Base de données :** Conception et requêtage SQL.

### 🚀 Points clés démontrés
- **Travail d'équipe :** Coordination et répartition des tâches pour mener à bien un projet multi-technologies.
- **Polyvalence technique :** Capacité à lier du traitement logiciel (Java) à une interface web (PHP).
- **Rigueur algorithmique :** Application des concepts fondamentaux pour l'extraction de connaissances à partir de données.

---
*Ce projet illustre ma capacité à collaborer efficacement sur des problématiques d'analyse de données et à livrer une solution technique complète.*
