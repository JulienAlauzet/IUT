# Simulation de système Tamagoshi 👾

Ce projet Java a été réalisé durant ma Licence Pro PSGI. Il s'agit d'une simulation de cycle de vie basée sur des automates à états simples, mettant l'accent sur la structure du code et la documentation technique.

### 🎯 Objectifs du projet
* **Logique métier :** Simuler les besoins et l'évolution d'une entité autonome (faim, sommeil, santé).
* **Conception POO :** Utilisation rigoureuse des modificateurs d'accès pour garantir l'encapsulation.
* **Documentation :** Mise en œuvre d'une structure de projet claire et auto-explicative.

### 🏗️ Structure du projet
Le projet est organisé pour séparer les niveaux de visibilité, une pratique essentielle pour la maintenance de gros systèmes :
* **src/tamagoshi :** Contient l'ensemble du code source Java.
* **Public / Private :** Dossiers illustrant la séparation des ressources selon leur portée et leur utilité dans l'architecture globale.

### 🛠️ Stack Technique
* **Langage :** Java.
* **Format :** Application console / Logique pure.

### 🚀 Ce que ce projet démontre
Au-delà de l'aspect ludique, ce projet reflète ma **volonté d'avoir une documentation efficiente** et un code organisé. En tant que futur **Lead**, je considère que la clarté d'un dépôt est aussi importante que la performance du code pour permettre une collaboration fluide au sein d'une équipe.
